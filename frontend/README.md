# 🍔 Foodworld - Food Ordering Website

## 📌 Project Overview

FoodHub is a simple Food Ordering Website developed as a summer intership and training project using HTML, CSS, JavaScript, Node.js, Express.js, and a JSON file for user data storage. The website allows users to browse food items, register, log in, add items to the cart, and place an order.

---------

## Features

- Home Page
- Food Menu
- Search Food
- Category Filter
- Add to Cart
- Shopping Cart
- Quantity Update
- Remove Items
- Order Summary
- Login
- Sign Up
- Simple Backend
- JSON File Storage
- Responsive Design

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/food-order-website.git
```

### 2. Open the Backend Folder

```bash
cd backend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Server

```bash
node server.js
```

The server will run on:

```
http://localhost:5000
```

### 5. Run the Frontend

Open the **frontend** folder in VS Code and start **Live Server**.

---

## 👨‍💻 How It Works

1. User opens the website.
2. User browses the food menu.
3. Food items are loaded from TheMealDB API.
4. User adds food to the cart.
5. Cart data is stored in Local Storage.
6. User creates an account or logs in.
7. User enters delivery details.
8. Order is placed successfully.
